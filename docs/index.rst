######################
FantasyProsApiClient
######################

``FantasyProsApiClient`` is a lightweight, framework-agnostic PHP client for
the FantasyPros public API (NFL). It wraps the API behind a small,
strongly-typed, fluent interface and maps every response onto plain PHP data
transfer objects (DTOs).

    This documentation is under construction. The package is being developed;
    the full documentation set (installation, endpoints, DTOs, error handling,
    extending, contribute) will be published alongside the first tagged
    release.
